Esta é uma tradução informativa. A versão canônica está em
[inglês](../../SECURITY.md).

O [threat model público](architecture/threat-model-de-seguranca.md) documenta
limites de confiança, riscos aceitos no alpha e requisitos de verificação. Ele
não substitui o relato privado de vulnerabilidades.

## Versões Suportadas

A Molejo é um projeto experimental em pre-alpha e não possui uma release
suportada ou versão pronta para produção. Correções de segurança são aplicadas à
branch padrão conforme a disponibilidade dos mantenedores.

## Relatando uma Vulnerabilidade

Relate suspeitas de vulnerabilidade pelo
[canal privado de vulnerabilidades do GitHub](https://github.com/molejo-platform/molejo/security/advisories/new).
Não divulgue a vulnerabilidade em uma issue, discussão ou pull request público.

Inclua, quando possível:

- o componente e a revisão afetados;
- passos para reprodução ou uma prova de conceito;
- o impacto esperado;
- mitigações conhecidas.

Os mantenedores confirmarão o recebimento e avaliarão o relato conforme sua
disponibilidade. Como o projeto está em pre-alpha, não existe atualmente um acordo
de nível de serviço para resposta ou correção.

## Divulgação

Permita que os mantenedores tenham uma oportunidade razoável para investigar e
preparar uma correção antes da divulgação pública. O crédito será coordenado com a
pessoa que fez o relato quando for apropriado e desejado.
