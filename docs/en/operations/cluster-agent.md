# Cluster Agent Operations

The Cluster Agent is a pre-alpha outbound connector. It does not reconcile
workloads yet. The Operator can be installed first; the Agent then starts as
`Unpaired`, remains ready, and waits for configuration without opening an inbound
management port.

## Installation identity

The installer must provide `required-external-agent-ca-secret` with `ca.crt` and
`ca.key`, plus `required-external-agent-server-tls` with `tls.crt` and `tls.key`,
in `fruto-control-plane`. The server certificate must cover
`control-plane-api.fruto-control-plane.svc.cluster.local`. Keep the CA key outside
Git and mount it only on the API pod.

The Agent ServiceAccount can only get, update, and patch
`molejo-agent-identity` and `molejo-agent-enrollment` in `fruto-system`. It cannot
list Secrets or access Molejo CRDs. The private key is generated by the Agent and
never leaves `molejo-agent-identity`.

## k3s release

The control-plane release build publishes the Agent as a separate immutable
`linux/amd64` image. `just control-plane-prepare-k3s` creates or reuses the
installer-owned ECDSA P-256 CA and internal server certificate outside the
checkout, then applies versioned Secrets. Rendering replaces those Secret names
and the Agent image placeholder; apply waits for the Agent Deployment. Keep the
external release directory protected because it contains the CA private key.

## Pairing

An installation administrator calls `POST /api/v1/admin/agent-installations`
with a name. The response returns a 256-bit enrollment token once; it expires in
ten minutes. Transfer it into the `token` key of `molejo-agent-enrollment`
without placing it in Git, shell history, logs, or chat.

The Agent persists its key, CSR, and attempt ID before enrollment, so a timeout
or crash retries the same operation. A successful response is validated against
the local key, Agent CA, certificate expiry, and installation URI before being
persisted. The token is then removed and the Agent opens the TLS 1.3 mTLS stream.

`/healthz` reports process health. `/readyz` remains successful in
`Unconfigured`, `Unpaired`, `Enrolling`, `Connecting`, and `Paired`; `/status`
exposes the current state without identity material. `Failed` means the local
identity Secret is unreadable, unwritable, partial, invalid, or expired.

This increment has no automatic certificate rotation. A seven-day certificate
must not be treated as a production lifecycle; re-pairing is the temporary
pre-alpha recovery path.
