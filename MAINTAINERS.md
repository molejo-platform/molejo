## Current Maintainer

- [@OliveiraCleidson](https://github.com/OliveiraCleidson) — project lead and
  repository administrator.

The maintainer is responsible for project direction, repository administration,
reviews, releases, security reports, and enforcement of the Code of Conduct.

## Future Maintainers

The project does not yet have a formal maintainer nomination process. A governance
policy will be introduced when sustained external participation makes one useful.
Maintainer status will be based on continued, trusted contributions and shared
responsibility for the project.
